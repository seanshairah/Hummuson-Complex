# Visual reference analysis — "Harvest — Smart Agriculture Hero UI"

Reference: https://dribbble.com/shots/27509096-Harvest-Smart-Agriculture-Hero-UI
(provided as the primary quality benchmark; studied from the supplied artwork).

## What makes the reference work

1. **Immersive full-bleed agricultural photography** — a real field scene fills the
   viewport; the interface floats *inside* the scene rather than sitting on a plain canvas.
2. **Dark-ground legibility** — deep green/near-black grading with controlled scrims keeps
   white display type crisp on photography.
3. **Oversized, confident typography** — a geometric grotesk at display sizes, with a
   colour accent inside the headline ("Smart & Sustainable Solutions" in leaf green).
4. **Floating data cards** — glassy panels (market prices, weather, daily schedule) that
   make the page feel like a living product, not a brochure.
5. **A grounded feature row** — translucent cards anchored to the photo's lower third.
6. **Real-feeling numbers** — a stats strip (happy farmers, advisors, satisfaction).
7. **Pill navigation + strong CTA pair** — a floating rounded nav and one accent action.
8. **Restraint** — one photo, two greens, generous spacing; nothing competes with the hero.

## How Humuson translates it (originally — no cloning)

| Reference principle          | Humuson execution                                                        |
| ---------------------------- | ------------------------------------------------------------------------ |
| Full-bleed field hero        | Humuson's **own** photo (seedlings + drip line in soil) with humus-950 grade + grain |
| Accent inside the headline   | "Healthy soil. Stronger crops. *Better harvests.*" — Fraunces italic in leaf-300 |
| Floating data cards          | Real data only: product spotlight (live DB record), WhatsApp adviser card (real free-consultation service), crop-programs card |
| Stats strip                  | Computed real numbers (22 products, crops covered, 3 European partner brands) — the reference's invented-style counters were explicitly rejected |
| Weather/schedule widgets     | Not imitated (no real data source) — replaced by knowledge-engine entry points |
| Pill nav                     | Floating pill nav that adapts dark↔light per route and scroll             |
| Feature row on imagery       | Benefit-led navigation cards driven by evidence-derived product benefits  |

## Where we deliberately diverge

- **Editorial serif accent (Fraunces)** gives Humuson an organic warmth the reference
  lacks — differentiating "soil company" from "SaaS dashboard".
- **Paper-warm light sections** alternate with dark immersive bands so long pages
  breathe; the reference is a single dark hero.
- **Honesty as a design feature** — confirm-with-support states, sourced answers in Ask
  Humuson, and reasons on finder recommendations are visible product decisions, not
  fine print.

## Quality checklist used across the build (§41 of the brief)

Intentional composition · premium type confidence · imagery integrated with interface ·
visual depth (layering, grain, glow, parallax) · custom (non-template) sections ·
"2026 product" feel — checked against screenshots at every milestone.
